## Reading the matrix

Each row is an emission branch, not a claim that the route has been exercised. All paths/methods below are observed unless explicitly marked NOT INSTALLED. `R` = owner or valid `guest:<label>` via `_auth`; anonymous also passes when viewer authentication is disabled (development fallback). `O` = owner required; guest/anonymous denied. `I` = ingest-authenticated emitter (anonymous only when ingest gate disabled); an owner/guest viewer token alone does not grant this role. `C` = bearer capability holder, independent of owner/guest viewer identity; a guest who possesses a valid capability can use that flow. `P` = unauthenticated public, also accessible to owner/guest.

`U` = user/source/emitter-controlled value, including stored prose, config-derived names and unrestricted DB strings; do not assume a semantic enum is validated simply because the client expects one. `K` = user/source-controlled **map key**. `S` = closed literal schema field name, code-generated label or validated enum. `ID/T/M` = stable identifiers, typed timestamps and metrics; preserve established values/types in the approved projection contract. Braces and `*` below describe field paths, not literal schema keys. Line references are to the enumerated source version.

Payload `action/risk` are extracted without type validation, so nested adversarial objects may carry K. This inventory reports current behavior; it does not approve the current cancelled-to-denied semantics over the separately approved approvals contract.

`V` = `redact.scrub_obj` recursively processes string VALUES only (`redact.py:69–77`); all dict keys are returned unchanged. Its existence does not prove confidentiality: compressed/loopback IPv6 and complete private-key/header handling are incomplete in the inspected regex implementation. Server redaction must precede serialization; HTML escaping is additional, never a substitute.

## Map-key decision input — do not silently rename keys

Observed arbitrary key exposure exists, so 'there are no exposed user-controlled maps' is false. Concrete K surfaces: `tool_counts`, `agents[].live_tool_counts`, `agents[].tool_stats`, unrestricted `agents[].state`, nested `context.messages/tools`, and malformed emitter values accepted without nested type validation. `scrub_obj` currently preserves every key, so planted credential-name keys survive even when string values are scrubbed.

Closed schema keys such as `input_tokens`, `requested_at`, `task_id`, `categories.running`, and OpenAPI authentication parameter names MUST remain byte-identical; do not run blanket key redaction that renames/collides them. The dynamic per-model aggregator is internal, not an exposed keyed map. Preserve canonical DB/snapshots/cache inputs, stable IDs, timestamps, numeric metrics, and established field names. This inventory does not authorize changing map representation/removing fields: revised projection contract and Meridian/schema-owner gate must settle those choices. Test sensitive K next to harmless K and pre-existing replacement-like keys to detect collisions, not merely value redaction.
